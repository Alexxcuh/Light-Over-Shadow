**Game Jam Submission** for the **Solo Development Game Jam #9**

**Theme:** *Black and White*

## About this game
This game is a fast-paced puzzle platformer, where you are a lamp and you are trying to reach the end in the shortest amount of time possible by using something called **light platforms** to cross gaps, of which you have a limited amount of.

The game also includes a **built-in level editor**, allowing players to create their own custom levels. These levels can be shared with others, enabling the community to create and enjoy an unlimited variety of new content.
